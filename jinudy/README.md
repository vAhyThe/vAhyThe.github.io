# Jinudy – prohlížeč historie

Webový prohlížeč sdílené historie z aplikace Jinudy. Statická stránka, bez serveru.

- Ukázka: `?demo`
- Soubor s historií se otevře přímo v prohlížeči a nikam se neodesílá.
- Odkazy na jednu cestu: `c/#…`

Podkladová mapa © OpenFreeMap, © OpenMapTiles, data © přispěvatelé OpenStreetMap.

Sestaveno z větve `web-viewer` soukromého repozitáře (`npm run build:viewer -w app`).
